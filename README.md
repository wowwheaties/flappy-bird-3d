# Flappy Bird 3D

A lightweight 3D Flappy Bird clone in the browser (Three.js). No install, no build step.

## Play

**Live:** https://wowwheaties.github.io/flappy-bird-3d/

Or open `index.html` via any static file server.

## Controls

| Input | Action |
|-------|--------|
| Space / click / tap | Flap |
| P | Pause |
| M | Mute |

## Tech

- Three.js r160 (CDN)
- Vanilla JS, single `js/game.js`
- Best score & mute saved in `localStorage` (stays on the player’s device only)
